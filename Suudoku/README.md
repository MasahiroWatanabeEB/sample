# Suudoku

iOS向けのシンプルな数独入力アプリです。SwiftUI で実装しており、9×9の盤面と数字入力用のナンバーパッドを備えています。

## 主な特徴

- 初期状態でサンプルの数独パズルを読み込み、ヒントマスは編集できないように保護。
- マスをタップして選択し、下部のナンバーパッドから数字を入力または削除。
- 3×3 ブロックのガイドラインやハイライトで視認性を向上。

## ビルド方法

1. Xcode 15 以降で `Suudoku/Suudoku.xcodeproj` を開きます。
2. ターゲット「Suudoku」を選択し、任意の iOS シミュレータまたはデバイスで実行してください。

## リポジトリの公開

1. GitHub 上で新しいリポジトリ `Suudoku` を作成します。
2. このプロジェクトのルートで `git remote add origin <your-remote-url>` を実行します。
3. `git push -u origin <branch>` でブランチを公開します。

## ソースコードをローカルに保存する

ローカル環境にソースコードを保存する方法は次の 2 通りがあります。

### 1. Git リポジトリとして保存する

1. 上記の手順で GitHub に公開したら、保存したいマシンで `git clone <your-remote-url>` を実行します。
2. クローンされたフォルダにプロジェクト一式が展開されるので、必要に応じてバックアップしてください。

### 2. ZIP アーカイブとして保存する

プロジェクトルートで次のスクリプトを実行すると、現在のソースを ZIP 化して `dist/` フォルダに保存できます。

```bash
./scripts/export_suudoku_source.sh
```

生成されたファイル（例: `dist/suudoku-source-YYYYMMDD-HHMMSS.zip`）を任意の場所にコピーすれば、ソースコードをまとめてバックアップできます。
